You are in the right folder when this file sits next to a folder named cursor_mac_migrate.

Do not open cursor_mac_migrate to run anything. That inner folder is only the program code. It does not contain migrate.sh. migrate.sh is in this same folder, beside cursor_mac_migrate.

Copy this whole parent folder to the Mac Desktop. On the Mac, quit Cursor, open Terminal (Command-Space, type Terminal, press Return), then paste:

cd "$HOME/Desktop"
ls

Find the name that is this parent folder (the one that contains THIS file). Then:

cd "$HOME/Desktop/THAT-NAME"
ls

You must see all of these names on one list:
  START-HERE.txt
  README.md
  pyproject.toml
  migrate.sh
  cursor_mac_migrate

Then paste:

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e ".[dev]"
python3 -m cursor_mac_migrate auto --windows-home 'C:\Users\janusz' --mac-home /Users/jh --also 'C:\DevWorkspaces=/Users/jh/DevWorkspaces'

That preview does not change Cursor. It writes lists in the migrate-work folder inside this tool folder.
Copy wanted lines from migrate-work/cursor-migrate-rename-suggested.txt into migrate-work/cursor-migrate-rename.txt.
Put chats you want to abandon into migrate-work/cursor-migrate-drop.txt, one Windows path per line.
Leave migrate-work/cursor-migrate-keep.txt alone. Those are missing copies, worktrees, and Roaming\Cursor\Workspaces.

Then, with Cursor still quit:

python3 -m cursor_mac_migrate auto --windows-home 'C:\Users\janusz' --mac-home /Users/jh --also 'C:\DevWorkspaces=/Users/jh/DevWorkspaces' --renames migrate-work/cursor-migrate-rename.txt --drop migrate-work/cursor-migrate-drop.txt --apply
